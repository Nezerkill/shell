# S0 — спайки (1.5 недели)

Каждый спайк — минимальный код, который отвечает на один вопрос и заканчивается
выводом «идём» / «меняем решение» + правкой соответствующего документа в
`docs/architecture/`. Спайки не мержатся в основные крейты, кроме тех, где
решение подтвердилось.

| # | Вопрос | Как проверить | Критерий |
|---|---|---|---|
| R1 | `ext-session-lock-v1` из Rust без готовых обёрток | прототип в `spikes/r1-esl` | лок/анлок, два монитора, кадр не раскрывается при ресайзе |
| R2 | wgpu blur/скругления на 4K@144 | `spikes/r2-render` + замер | кадр ≤ 6.9 мс, blur без артефактов |
| R3 | PAM на NixOS без внешнего хелпера | `spikes/r3-pam` + `pam.services.shell` | анлок паролем и fprint, сборка только из своего дерева |
| R4 | яркость внешних мониторов (ddcutil/i2c) | `spikes/r4-ddc` | время отклика, поведение при отсутствии монитора |
| R5 | `ext-image-copy-capture-v1` в wayland-protocols | `spikes/r5-capture` | либо крейт, либо vendored XML — решение записано |
| R6 | генератор KDL-binds для Niri | `spikes/r6-binds` | фрагмент проходит `niri validate` |
| R7 | краш dylib-плагина | `spikes/r7-dylib` | паника ловится, segfault убивает процесс, автодизейбл срабатывает |

Порядок: R3 и R7 (дёшево, много риска), затем R1, R5, R6, R2, R4.
