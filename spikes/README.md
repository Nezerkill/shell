# S0 — спайки (1.5 недели)

- **Статус:** этап закрыт, 2026-11-17 — все семь спайков закончены, вердикты в таблице ниже; номер спайка ведёт на его `RESULT.md`.

Каждый спайк — минимальный код, который отвечает на один вопрос и заканчивается
выводом «идём» / «меняем решение» + правкой соответствующего документа в
`docs/architecture/`. Спайки не мержатся в основные крейты, кроме тех, где
решение подтвердилось.

| # | Вопрос | Как проверить | Критерий | Вердикт |
|---|---|---|---|---|
| [R1](r1-esl/RESULT.md) | `ext-session-lock-v1` из Rust без готовых обёрток | прототип в `spikes/r1-esl` | лок/анлок, два монитора, кадр не раскрывается при ресайзе | **идём** — лок/анлок, два выхода, устойчивость к SIGKILL, ресайз проверены на wlroots/headless sway; на Hyprland только наличие менеджера |
| [R2](r2-render/RESULT.md) | wgpu blur/скругления на 4K@144 | `spikes/r2-render` + замер | кадр ≤ 6.9 мс, blur без артефактов | **идём** — 4K offscreen p50 0.86 мс при бюджете 6.9 мс |
| [R3](r3-pam/RESULT.md) | PAM на NixOS без внешнего хелпера | `spikes/r3-pam` + `pam.services.shell` | анлок паролем и fprint, сборка только из своего дерева | **идём** — PAM на NixOS без внешнего хелпера: raw FFI к системной `libpam`, стек реально доходит до `pam_unix` (`PAM_AUTH_ERR` на неверный пароль), свой confdir работает; успешный анлок и fprint не проверены — нужен `security.pam.services.shell` в dotfiles |

| [R7](r7-dylib/RESULT.md) | краш dylib-плагина | `spikes/r7-dylib` | паника ловится, segfault убивает процесс, автодизейбл срабатывает | **идём с оговоркой** — паника ловится только ручным `catch_unwind` в плагине; segv/abort убивают процесс, поэтому автодизейбл обязан опираться на смерть процесса |
