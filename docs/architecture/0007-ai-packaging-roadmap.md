- **Статус:** согласовано (этап 7 из 7), 2026-11-17
- **Предыдущий:** `0006-theme-plugins-api.md`
- **Решения этапа:** OCR — локальный приоритет, облако опционально; AI — облачные провайдеры по умолчанию; подтверждение всех изменяющих действий ассистента; сервисы и бар раньше «красоты»; старт практической части — скелет + спайки S0.

## 1. AI-подсистема

```
shell-ai
├── providers/   openai-compatible · anthropic · gemini · ollama (local) · llama.cpp
├── tools/       реестр: имя + JSON Schema + IPC-команда + политика подтверждения
├── ocr/         захват области → OCR → перевод → оверлей
├── web/         поиск (SearxNG/Brave/Tavily/DDG) + fetch + суммаризация с цитатами
└── audit/       локальный журнал вызовов
```

- **Провайдеры по умолчанию — облачные** (OpenAI-совместимый / Anthropic / Gemini), ключи из Secret Service. Локальный Ollama добавляется как провайдер и включается переключателем.
- **Tool-calling**: инструмент = существующая IPC-команда + JSON Schema. Все **изменяющие** действия требуют подтверждения с diff-предпросмотром («изменить `bar.position`: `top` → `bottom`»); read-only (`launcher.query`, `compositor.state`) — без подтверждения.
- **Приватность**: `ai.online` управляет облаком; при `false` остаются только локальные модели. Журнал вызовов — локальный, телеметрии нет.
- **OCR-перевод**: область → `tesseract` локально → перевод → оверлей + копирование. Если в настройках включено и есть ключ — можно отправить область в vision-модель (лучше на скриншотах с вёрсткой). Горячая клавиша по умолчанию `SUPER+ALT+T`.
- **Веб-поиск**: провайдер + fetch + суммаризация **с обязательными ссылками**, кэш, лимиты времени/размера.
- Всё — задачи tokio, стриминг в UI, отмена по Escape.

## 2. Nix-упаковка

| Что | Где |
|---|---|
| `packages.{shelld,shell-ui,shell-lock,shellctl}` + `plugins.*` | flake `~/shell` |
| NixOS-модуль: systemd user units, polkit, PAM-сервис, порталы | `modules/nixos` |
| HM-модуль: `settings`, `locked`, `plugins`, `generated`, `binds`, `theme.targets` | `modules/home-manager` |
| Бинарный кэш | Cachix |
| Интеграция с dotfiles | `inputs.shell.url = "path:~/shell"` |

Обязательные детали:

- **PAM** (R3): модуль генерирует `security.pam.services.shell` (`pam_unix` + `pam_fprintd` при наличии); `shell-lock` линкуется к системной `libpam`.
- **systemd**: `shelld.service` (`Type=notify`, `Restart=always`, `After=graphical-session.target`), `shell-ui.service` (`Restart=always`), `shell-lock` — по требованию.
- **Hardening**: `NoNewPrivileges`, `PrivateTmp`, `ProtectSystem=strict` + явные `ReadWritePaths`; `RestrictAddressFamilies` ослабляется для плагинов с `exec`.
- **Порталы**: `xdg.portal.config` — `-hyprland` для Hyprland, `-gnome` для Niri (GlobalShortcuts/ScreenCast).
- **Конфликты**: `services.guard = true` отключает mako/swaync/nm-applet.

## 5. Риск-регистр

| Риск | Вер-ть | Влияние | Митигация |
|---|---|---|---|
| Свой рендер дольше ожидаемого | низкая (измерено в R2) | +4–6 недель → пересмотреть вниз | R2: 4K offscreen p50 0.86 мс, p95 1.17 мс при бюджете 6.9 мс; остаток риска — реальный скаутаут, damage tracking, текст (не измерены) |
| `xdg_popup`-грабы на двух композиторах | средняя | баги панелей | `PopupBackend` + проба + фолбэк |
| PAM на NixOS | **закрыт R3** | — | R3: raw FFI к системной `libpam` 1.7.2, тесты через `pam_start_confdir`, `security.pam.services.shell` |
| dylib-плагин роняет процесс | средняя | потеря сервисов | R7: паника ловится **только** ручным `catch_unwind` в entry point плагина — abi_stable сам панику не ловит, а его `extern_fn_panic_handling!` даёт abort; segv/abort/OOM убивают процесс, поэтому автодизейбл — по факту смерти процесса (systemd `Restart=always` + счётчик рестартов), в профиле плагинов запрещён `panic = "abort"`, в `shell-lock` плагинов нет |
| Лок: политика на Hyprland не проверена | низкая | лок не встаёт на живой сессии | R1 проверен на wlroots/headless sway (лок/анлок, два выхода, SIGKILL, ресайз); на Hyprland подтверждено только наличие `ext_session_lock_manager_v1` |
| wgpu молча не видит адаптеров в упакованной сборке | высокая | «нет GPU» на NixOS | wgpu грузит `libvulkan.so.1` через `dlopen`; нужен `LD_LIBRARY_PATH` или `-rpath` из `pkg-config` (R2), smoke-тест в CI |
| Трей больше плана | высокая | +1–2 недели | оценка 3 недели, XEmbed не поддерживаем |
| Мотивация на дистанции | высокая | проект встаёт | v0.1 полезен уже на 2–3 месяце |

Режимы отказа плагина по R7 (коды выхода): паника — 0 при своём `catch_unwind` и 134 без него; segv — 139; abort и OOM — 134; несовпадение `plugin_api` отбивается до вызова (3). Счётчик падений берём у systemd (`NRestarts`), а не у плагина.
