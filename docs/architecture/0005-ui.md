## 1. Поверхности

| Поверхность | layer | exclusive_zone | keyboard |
|---|---|---|---|
| Бар | `top` | да | нет |
| Панели (control center, нотификации, дашборд, календарь) | `overlay` | нет | по требованию |
| Лаунчер | `overlay` | нет | exclusive |
| Док | `top`/`bottom` | опционально | нет |
| OSD | `overlay` | нет | нет |
| Overview (Hyprland) | `overlay` | нет | exclusive |
| Обои | `background` | нет | нет |
| Лок | `ext-session-lock` | — | exclusive |

На Niri бар на `top` остаётся выше overview (протокольное свойство); обои — `background` + `layer-rule { place-within-backdrop true }` (генерируем в своём фрагменте конфига).

## 2. Попапы: xdg_popup с невидимым toplevel-родителем

Схема:
1. Один невидимый `xdg_toplevel` (1×1, прозрачный, вне видимой области, на нужном выходе) — «якорь».
2. Попап — `xdg_popup` под ним, позиция по `set_anchor_rect` + `set_position` от геометрии виджета.
3. Закрытие: `xdg_grab` (pointer + keyboard) + Escape; клик-вне приходит как `popup_done`.
4. Вложенные подменю — `xdg_popup` от попапа.
5. Пересчёт при: смене выхода, `ui_scale`, прокрутке содержимого, hotplug.

**Риск (фиксируем осознанно):** позиционирование попапов от невидимого toplevel-родителя и грабы по-разному реализованы в Hyprland и Niri. Поэтому:

```rust
trait PopupBackend { fn show(&mut self, spec: PopupSpec) -> Result<PopupId>; fn close(&mut self, id: PopupId); }
// XdgBackend (по умолчанию) + OverlayBackend (overlay-поверхность + click-catcher)
```
На старте выполняется проба (создать тестовый попап, проверить позицию и grab). Провал → автоматический фолбэк на `OverlayBackend` с записью в лог и бейджем. Оба бэкенда дают одинаковый UX, различается только механика.

## 3. Рендер

- Один `wgpu`-device, поверхность + swapchain на каждый выход.
- Retained scene graph с dirty-флагами; инвалидация по состоянию/токену/размеру.
- Damage tracking: частичная перерисовка; полный кадр — только тема/выход/крупная анимация.
- Frame pacing по `wl_surface.frame`; при простое — 0 fps (1 Гц тик для часов).
- Скругления/границы — SDF-шейдеры (чётко на любом масштабе), сложные фигуры — `lyon`.
- Текст — `cosmic-text` + `glyphon`, grayscale AA.
- Изображения — LRU-кэш декодированных, ресайз под физический пиксель.

### Blur

Свой блюр «того, что за панелью» без чтения чужих пикселей невозможен.

| | Как |
|---|---|
| Hyprland | `layerrule = blur, shell-bar` в генерируемом фрагменте |
| Niri | blur панелей отсутствует → полупрозрачный градиент/шум |

`Capability::PANEL_BLUR`; тема имеет пресеты `blur` / `solid`.

## 4. Бар и layout

- `Bar { monitor, position, zones: [start, center, end], auto_hide, exclusive, height, margin, gap }`.
- Размеры виджета: `hug` / `fill` / `fixed(px)`.
- Все четыре стороны: вертикальные бары — тот же layout с транспонированной осью.
- Per-monitor оверрайды по `OutputId`.
- Auto-hide: триггер по краю через input region, задержка, скрытие при фуллскрине (по состоянию композитора).
- Drag-and-drop виджетов между зонами в баре → транзакция конфига → кнопка «сохранить в Nix».

## 5. Виджеты v1

workspaces, window title, clock, calendar, media, tray, notifications badge, battery, network, bluetooth, volume, mic, brightness, keyboard layout, CPU/RAM/GPU/net, weather, clipboard, privacy (mic/cam/share), updates (nix), custom-script, spacer.

Каждый виджет объявляет **схему настроек** → автоген формы в GUI и валидация в Nix (стык с `0002`). Плагинные виджеты приходят декларативным деревом и живут в тех же зонах.

## 6. Токены и тема

`shell-tokens`: палитра, spacing (база 4 px), радиусы, типографика, тени, параметры блюра, длительности/easing, набор `reduced-motion`, набор `high-contrast`. Смена палитры анимируется интерполяцией 150–250 мс.

## 7. Масштаб и мониторы

- `wl_output.scale` + `wp_fractional_scale_v1` + пользовательские `ui_scale` и `font_scale`.
- Матрица тестов: 1.0 / 1.25 / 1.5 / 2.0 и два монитора с разными масштабами.
- Hotplug: создание/уничтожение поверхностей, пере-привязка конфига по `OutputId`, сохранение позиции попапов.

## 8. Ввод и IME

- Input region только по фактическим виджетам (иначе бар съедает клики).
- Клавиатурная навигация в лаунчере/панелях, фокус-ринг из токенов.
- **`zwp_text_input_v3` в поле поиска** — блокер для русского языка (fcitx5), включён в спайк этапа 0.

## 9. Доступность

Клавиатурная навигация, reduced-motion, high-contrast. AT-SPI/скринридер — вне v1 (записанное ограничение).

## 10. Бюджеты и тесты

| Метрика | Бюджет |
|---|---|
| Idle CPU бара | < 0.5 % |
| RSS `shell-ui` | < 120 МБ |
| Кадр при анимации (144 Гц) | ≤ 6.9 мс |
| Частичная перерисовка | ≤ 2 мс |
| Старт до первого кадра | ≤ 150 мс |

Тесты: offscreen-рендер → PNG → golden-сравнение; юнит-тесты layout (вход → прямоугольники); проверка бюджета кадра на синтетической сцене в CI.
